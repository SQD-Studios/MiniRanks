# MiniRanks

A "simple" plugin (That's why it's called mini), that does 1 thing. Give "ranks" (LuckPerms Groups). It doesn't provide
any cosmetic stuff, like custom chat, image prefixes or anything like that. For that use TAB for most stuff
and [Irene](https://github.com/SQD-Studios/Irene) for the chat. To give players ranks, you create "Notes" which can do
the following things:

- Give players the rank
- Upgrade the player's rank
- Give a rank to the player for a limited amount of time

That means we only provide 2 commands (Except reload).

`/miniranks give normal <target> <group/rank> [amount] [endsInDays]` - `miniranks.admin`

and

`/miniranks give upgrade <target> <group/rank> [amount]` - `miniranks.admin`

The commands themselves are pretty self explanatory

### Dependencies

- LuckPerms (Genuinely, who doesn't use luckperms, if you don't please change that)
